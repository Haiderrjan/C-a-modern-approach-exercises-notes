### Exercise 7.15

Use `typedef` to create types names `Int8`, 
`Int16`, and `Int32`. Define the types so that 
they represent 8-bit, 16-bit and 32-bit integers 
on your machine.

### Answer:

```
 typedef char Int8;   // 8 bits (1 byte) of memory
 typedef short Int16; // 16 bits (2 bytes) of memory
 typedef int Int32;   // 32 bits (4 bytes) of memory

```
