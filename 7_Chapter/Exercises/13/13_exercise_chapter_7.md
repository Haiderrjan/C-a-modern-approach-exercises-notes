### Exercise 7.13


Assume that a program contains the following 
declarations:

```
char c = '\1';
short s = 2;
int i = -3;
long m = 5;
float f = 6.5f;
double d = 7.5;
```

Give the value and the type of each expression 
listed below.


**(a)** `c * i`

**(b)** `s + m`

**(c)** `f / c`

**(d)** `d / s`

**(e)** `f - d`

**(f)** `(int) f`

### Answer:

**(a)** `c * i` = `-3`  `int`

**(b)** `s + m` = `7`  `long`

**(c)** `f / c` = `6.500000`  `float`

**(d)** `d / s` = `3.750000`  `double`

**(e)** `f - d` = `-1.000000`  `double`

**(f)** `(int) f` = `6` `int`
