### Exercise 6.02
What output does the following program fragment produce?

```
i = 9384;
do {
printf("%d ", i);
i /= 10;
} while (i > 0);

```
My answer the output is: 
`9384 938 93 9`

The program loop once and prints the initial number to the terminal and then 
divides it by 10 everytime and checks to see if the number is more than zero. 
If less the program ends.
